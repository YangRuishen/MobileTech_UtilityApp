# SkySnap – A Glanceable Weather Utility App

A simple Android weather app showing current conditions at a glance.

## Core Features
- At-a-glance current weather: temperature, condition, feels-like, humidity, wind
- Settings: choose from 5 Australian cities, switch °C/°F
- Loading and error states with retry

## Implementation
- Jetpack Compose + Material Design 3
- MVVM architecture: ViewModel / Repository / manual dependency injection (ServiceLocator)
- Networking: Retrofit + Gson, Open-Meteo API (https://open-meteo.com)
